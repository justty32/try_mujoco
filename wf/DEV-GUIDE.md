# DEV-GUIDE — 結構整理參考

← [INDEX.md](INDEX.md)

本檔只在拆大檔、分類雜亂目錄或建立子工作流時使用。日常規則見 [AGENTS.md](../AGENTS.md)，程式碼規則見 [common/conventions.md](workflows/common/conventions.md)。

## 觸發條件

- `wf/` 流程文件超過 8192 bytes。
- 使用文件或原始碼單檔超過 300 行。
- 同一資料夾混入多種用途，已難以導航。

門檻用來觸發檢視，不是硬性上限。本質不可分的規格或報告可保留單檔；已完成且不再維護的規格移入對應 `archive/`。

## 整理方法

1. 依職責或用途拆分，不做機械式等分。
2. 放入有語意的子資料夾或既有領域檔。
3. 子資料夾保留 README 或 INDEX 導航。
4. 上層只保留摘要與指向下一層的連結。

工作流從單檔開始；需要擴充時才依序長成「資料夾＋README」、「多檔分工」、「巢狀子工作流」。內容縮小時可以反向合併。

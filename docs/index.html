robot

MuJoCo C 專案 · three_cylinders.xml · 控制 yaw / pitch motor，監控關節角度、位置與受力

架構

四個模組，單向依賴，sim 在最底層，main 在最頂層。

sim.c ← controller.c ← viewer.c ⠀⠀ main.c

箭頭 = 「被誰 include」。sim 不依賴任何人；main 依賴全部。
viewer.c 的 callback 可直接呼叫 sim_reset() 與 ctrl_set_phase()，方向不倒流。

模型結構（three_cylinders.xml）

BodyJointActuator範圍
base_cylinder—（固定在世界）——
top_cylinderyaw_joint（繞 Z）yaw_motor [0]±90°
pitch_cylinderpitch_joint（繞 X）pitch_motor [1]±60°

simsim.h / sim.c

擁有 mjModel* 和 mjData*。所有物理計算、狀態讀取都在此層。其他模組透過 accessor 取得指標，不直接持有。

void sim_load(const char *path)

從 XML 路徑載入 MuJoCo 模型。依序：mj_loadXML → mj_makeData → sim_reset()。

成功後印出 body / joint / actuator 數量。載入失敗時 exit(1)。

參數說明
pathXML 路徑（相對於執行時工作目錄，請從 project root 執行）
void sim_unload()

釋放 mjData 與 mjModel，指標清為 NULL。程式結束時呼叫，通常在 viewer_free() 之後。

void sim_reset()

重置為 XML 定義的初始狀態（qpos = 初始值，qvel = 0，time = 0），並執行 forward kinematics。

Viewer 的 Backspace 會呼叫此函數，接著呼叫 ctrl_apply()。

void sim_step()

推進一個物理時間步（m→opt.timestep，預設 2 ms）。必須在呼叫前先寫入 d→ctrl[]。

主迴圈頻率：每渲染幀呼叫約 8 次（1/60 s ÷ 2 ms），以維持實時速度。
mjModel* sim_model()   mjData* sim_data()

取得全域指標，在 sim_load() 之後才有效。

mjModel：唯讀的結構描述（幾何、拓撲、物理參數）。
mjData：所有動態狀態，含 qpos / qvel / ctrl / xpos / xquat / actuator_force 等。

Returns：內部靜態指標，呼叫方不應 free。
double sim_joint_angle_deg(const char *name)
double sim_joint_vel_deg(const char *name) State Monitor — 角度

以名稱查詢關節的當前角度（度）或角速度（度/s）。

name對應 body旋轉軸範圍
"yaw_joint"top_cylinderZ 軸±90°
"pitch_joint"pitch_cylinderX 軸±60°
Returns：找不到名稱時回傳 0.0。
int sim_body_pos(const char *name, double pos[3]) State Monitor — 位置

將 name 對應 body 的世界座標（x, y, z，單位 m）填入 pos[3]。

Body初始位置（世界座標）說明
"base_cylinder"(0, 0, 0.2)固定底座
"top_cylinder"(0, 0, 0.5)Yaw 關節所在
"pitch_cylinder"(0, 0, 0.7)Pitch 關節所在
Returns：0 成功，−1 找不到 body。
/* 使用範例 */
double pos[3];
if (sim_body_pos("pitch_cylinder", pos) == 0)
    printf("tip: %.3f %.3f %.3f\n", pos[0], pos[1], pos[2]);
double sim_actuator_force(int index) State Monitor — 受力

回傳 actuator 實際輸出的力（經過 gear 放大後，單位 N·m）。

indexActuatorgear說明
0yaw_motor10yaw 關節力矩
1pitch_motor10pitch 關節力矩
注意：值來自 d→actuator_force[index]，是 MuJoCo 計算的實際輸出力， 受 joint limit 影響時可能與 ctrl 值不成正比。靜止時因 damping 接近 0。
Returns：index 超出範圍時回傳 0.0。

controllercontroller.h / controller.c

管理 motor 的 phase 狀態，並將預設的控制值寫入 d→ctrl[]。這層是主要的馬達操控入口。

Phase Preset 對照

Phaseyaw_motor ctrl[0]pitch_motor ctrl[1]效果
1+1.00.0Yaw 正向旋轉至 +90° 限制
20.0+0.5Pitch 正向旋轉至 +60° 限制
3−0.8−0.3兩者反向旋轉
void ctrl_init()

初始化控制器：設 phase = 1，立即呼叫 ctrl_apply()。在 sim_load() 之後、主迴圈之前呼叫。

void ctrl_set_phase(int phase)   int ctrl_get_phase() Motor Control

ctrl_set_phase：切換 preset（1–3），超出範圍忽略。不立即更新 d→ctrl[]，改變在下一次 ctrl_apply() 時生效。

ctrl_get_phase：回傳目前 phase 號碼（HUD 顯示用）。

Viewer 的 1 / 2 / 3 鍵直接呼叫 ctrl_set_phase。

void ctrl_apply() Motor Control

根據目前 phase 將控制值寫入 sim_data()→ctrl[0]（yaw）和 ctrl[1]（pitch）。

在主迴圈中每次 sim_step() 之前呼叫：

while (sim_data()->time - start < SIM_PER_FRAME) {
    ctrl_apply();   /* ← 寫入 ctrl[] */
    sim_step();     /* mj_step 讀取 ctrl[] 並積分 */
}
void ctrl_set_motors(double yaw, double pitch) Motor Control

直接將任意值寫入 d→ctrl[0]（yaw）和 d→ctrl[1]（pitch），不透過 phase 邏輯。

參數說明
yawyaw_motor 控制輸入（gear=10，輸出力矩 = yaw × 10 N·m）
pitchpitch_motor 控制輸入
注意：若主迴圈持續呼叫 ctrl_apply()，每幀都會用 phase 值覆蓋此處的設定。 手動控制時，在主迴圈中以 ctrl_set_motors() 取代 ctrl_apply()。

viewerviewer.h / viewer.c

封裝 GLFW 視窗、OpenGL context、MuJoCo 視覺化（mjvCamera、mjvScene、mjrContext），及所有輸入 callback 與 HUD 文字渲染。

Space暫停 / 繼續paused ^= 1
Backspace重置模擬sim_reset() + ctrl_apply()
1 / 2 / 3切換 motor phasectrl_set_phase()

滑鼠控制

操作動作
左鍵拖曳旋轉視角
右鍵拖曳垂直平移
Shift + 右鍵拖曳水平平移
中鍵 / 滾輪縮放
int viewer_init(int width, int height, const char *title)

建立 GLFW 視窗並完成視覺化初始化：

  1. glfwInit() + glfwCreateWindow()
  2. 啟用 vsync（glfwSwapInterval(1) → ~60 fps）
  3. 註冊 keyboard / mouse button / mouse move / scroll callback
  4. mjv_makeScene + mjr_makeContext（需要 OpenGL context，glfwMakeContextCurrent 後才可呼叫）
  5. 設定初始相機：lookat (0, 0, 0.4)、distance 2 m、azimuth 135°、elevation −20°
前置條件：必須在 sim_load() 之後呼叫（需要 sim_model()）。
Returns：1 成功，0 失敗。
void viewer_free()

釋放順序：mjr_freeContext → mjv_freeScene → glfwDestroyWindow → glfwTerminate。

int viewer_should_close()   int viewer_is_paused()

viewer_should_close：Esc 或點擊 ✕ 後為 1，主迴圈的終止條件。

viewer_is_paused：為 1 時主迴圈跳過 sim step，畫面凍結但仍可旋轉視角。

void viewer_render()

一幀的完整渲染流程：

  1. glfwGetFramebufferSize：取得實際 pixel 大小（HiDPI 適配）
  2. mjv_updateScene：從 model / data 計算場景幾何
  3. mjr_render：OpenGL 繪製
  4. mjr_overlay：左上角疊加 HUD（時間、關節角度、ctrl、快捷鍵）
  5. glfwSwapBuffers：顯示（vsync 在此阻塞，約 16 ms）
  6. glfwPollEvents：觸發所有 input callback

main主迴圈模式

main.c 不持有任何狀態，只負責串接與時序控制。

sim_load(MODEL_PATH);
ctrl_init();
viewer_init(1200, 900, "MuJoCo - Three Cylinders");

while (!viewer_should_close()) {
    if (!viewer_is_paused()) {
        mjtNum start = sim_data()->time;
        while (sim_data()->time - start < SIM_PER_FRAME) {
            ctrl_apply();   /* [Motor Control] 寫入 ctrl[] */
            sim_step();     /* 推進 2 ms */
        }                   /* ≈ 8 次 / 幀，維持實時速度 */
    }
    viewer_render();        /* 渲染 + vsync */
}

viewer_free();
sim_unload();

擴充：手動控制 motor

以 ctrl_set_motors() 取代 ctrl_apply()，傳入任意值：

/* 正弦波控制範例 */
double t = sim_data()->time;
ctrl_set_motors(sin(t * 2.0), cos(t * 1.5) * 0.5);
sim_step();

擴充：讀取完整狀態

/* 角度與角速度 */
double yaw   = sim_joint_angle_deg("yaw_joint");
double yaw_v = sim_joint_vel_deg("yaw_joint");

/* body 世界座標 */
double pos[3];
sim_body_pos("pitch_cylinder", pos);   /* pos = {x, y, z} */

/* actuator 實際輸出力 */
double f_yaw   = sim_actuator_force(0);  /* yaw_motor */
double f_pitch = sim_actuator_force(1);  /* pitch_motor */

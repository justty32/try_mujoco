robot

MuJoCo C 專案 · 9 圓柱 6R 手臂 · 調整關節目標角並保持姿態，或切換定力矩示範

先試：開啟後是 POSE HOLD。按 F1 選 J1 Base，再按兩次 →，目標變為 +10°；Home 讓目標回到核准的 home。完整按鍵見 viewer。

架構

四個模組，單向依賴，sim 在最底層，main 在最頂層。

sim.c ← controller.c ← viewer.c ⠀⠀ main.c

箭頭 = 「被誰 include」。sim 不依賴任何人；main 依賴全部。
viewer.c 的 callback 可直接呼叫 sim_reset() 與 ctrl_set_phase()，方向不倒流。

正式模型：assets/six_axis_arm.xml

使用者核准的 9 圓柱 6R 外形：底座 yaw、肩／肘 pitch，接緊湊手腕 roll／pitch／roll。比例、外形與軸沿用 核准原型圖；原型 XML、PNG 與拍攝 metadata 保留在 原型目錄。

home 為 [0, 65, -100, 0, 35, 0]°，不是全零姿態；正式 XML 的 keyframe qpos 使用弧度。固定 body 為 base，末端 site 為 tool_center。下表旋轉軸是各關節的局部軸，不能當成任意姿態下的世界座標軸。

BodyJoint（索引依序 0–5）局部軸角度範圍home
waistJ1_base_yawZ−180°～180°0°
shoulderJ2_shoulder_pitch−Y−100°～130°65°
elbowJ3_elbow_pitch−Y−145°～145°-100°
wrist_rollJ4_wrist_rollX−180°～180°0°
wrist_pitchJ5_wrist_pitch−Y−45°～45°35°
tool_rollJ6_tool_rollX−180°～180°0°

密度 1000 kg/m³、joint damping 0.1 為教學原型參數，尚非硬體校準。真實碰撞保留；關節限位與有限取樣都不能保證全部組合／路徑無碰撞。

J5 正式限位收為 ±45°，腕部在此邊界約有 2.373 mm 間隙；±50° 僅約 0.487 mm，±52° 開始相交。只調整操作限位，home 35°、原型的比例、外形與旋轉軸不變。見 正式接入驗證／正式模型預覽。

J6 工具法蘭為旋轉對稱圓柱，roll 時外形與末端位置可能看起來不變；請用 HUD 的 actual 角度判斷是否旋轉。末端方向與末端位置是不同量。

simsim.h / sim.c

擁有 mjModel* 和 mjData*。所有物理計算、狀態讀取都在此層。其他模組透過 accessor 取得指標，不直接持有。

void sim_load(const char *path)

從 XML 路徑載入 MuJoCo 模型。依序：mj_loadXML → mj_makeData → sim_reset()。

成功後印出 body / joint / actuator 數量。載入失敗時 exit(1)。

參數說明
pathXML 路徑（相對於執行時工作目錄，請從 project root 執行）
void sim_unload()

釋放 mjData 與 mjModel，指標清為 NULL。程式結束時呼叫，通常在 viewer_free() 之後。

void sim_reset()

優先載入 XML 的 home keyframe，沒有 home 才使用模型預設 reset；再執行 forward kinematics。正式模型以六個 home 角度開始，速度與時間歸零。

Viewer 的 Backspace 會呼叫此函數，接著呼叫 ctrl_home_targets() 與 ctrl_apply()，回到 home 姿態模式。暫停狀態保持不變。

void sim_step()

推進一個物理時間步（m→opt.timestep，預設 2 ms）。必須在呼叫前先寫入 d→ctrl[]。

主迴圈頻率：每渲染幀呼叫約 8 次（1/60 s ÷ 2 ms），以維持實時速度。
mjModel* sim_model()   mjData* sim_data()

取得全域指標，在 sim_load() 之後才有效。

mjModel：唯讀的結構描述（幾何、拓撲、物理參數）。
mjData：所有動態狀態，含 qpos / qvel / ctrl / xpos / xquat / actuator_force 等。

Returns：內部靜態指標，呼叫方不應 free。
double sim_joint_angle_deg(const char *name)
double sim_joint_vel_deg(const char *name) State Monitor — 角度

以名稱查詢關節的當前角度（度）或角速度（度/s）。

具名查詢使用上方模型表中的完整名稱，例如 J2_shoulder_pitch；HUD 使用短名，API 不接受 J2 Shoulder 當名稱。

Returns：找不到名稱時回傳 0.0。
int sim_body_pos(const char *name, double pos[3]) State Monitor — 位置

將 name 對應 body 的世界座標（x, y, z，單位 m）填入 pos[3]。

可查詢 base、waist、shoulder、elbow、wrist_roll、wrist_pitch、tool_roll。座標依目前姿態變化；tool_roll 是 body 原點，與末端 tool_center site 不同。

Returns：0 成功，−1 找不到 body。
/* 使用範例 */
double pos[3];
if (sim_body_pos("tool_roll", pos) == 0)
    printf("tool body: %.3f %.3f %.3f\n", pos[0], pos[1], pos[2]);
double sim_actuator_force(int index) State Monitor — 受力

回傳 MuJoCo 的 actuator 純量輸出，尚未乘上 gear。此模型是一個 hinge joint 對應一個 motor，關節力矩為此值乘上對應 gear（N·m）。

index / motor對應關節gearctrl ±1 的力矩額定
0 / J1_motorJ1_base_yaw12±12 N·m
1 / J2_motorJ2_shoulder_pitch20±20 N·m
2 / J3_motorJ3_elbow_pitch12±12 N·m
3 / J4_motorJ4_wrist_roll3±3 N·m
4 / J5_motorJ5_wrist_pitch3±3 N·m
5 / J6_motorJ6_tool_roll2±2 N·m

此額定只用於目前教學模擬，不代表任何真實馬達的規格。

注意：值來自 d→actuator_force[index]，不含接觸／關節限位的約束力。姿態保持時必須抵抗重力，因此即使靜止也可有非零輸出。
Returns：index 超出範圍時回傳 0.0。

controllercontroller.h / controller.c

預設以關節目標角控制並保持姿態；也可切回定力矩 phase。每個物理步由 ctrl_apply() 寫入 d→ctrl[]。

這是關節角控制，不是末端位置／姿態的反向運動學。目標有限位、內部目標以最多 30°/s 移動，輸出有力矩限幅；碰撞阻擋的姿勢不保證可達。

Phase Preset 對照

數值是正常化控制輸入，按 J1–J6 排列，所有模式均限制在 ±1。這些是力矩示範，不會自動到達指定角度。

PhaseJ1, J2, J3, J4, J5, J6作用
1[0.25, 0, 0, 0.10, 0, 0.10]底座／roll：J1、J4、J6
2[0, 0.35, 0.25, 0, 0.10, 0]pitch：J2、J3、J5
3[-0.20, -0.25, -0.20, -0.10, -0.10, -0.10]全部反向
void ctrl_init()

在 sim_load() 之後、主迴圈之前初始化具名關節與馬達，捕捉載入後的目前角度並進入姿態模式（正式模型為 home）。phase 編號預設為 1，但只有切換到 phase 模式後才套用。

void ctrl_set_phase(int phase)   int ctrl_get_phase() Motor Control

ctrl_set_phase：切換到定力矩 preset（1–3），超出範圍忽略；下一次 ctrl_apply() 寫入目前 preset 值。所有模式均使用模型的 ±1 控制範圍，此模式不追蹤角度目標。

ctrl_get_phase：回傳最近選擇的 phase 號碼；用 ctrl_get_mode() 區分 CTRL_MODE_POSE 與 CTRL_MODE_PHASE。

Viewer 的 1 / 2 / 3 鍵直接呼叫 ctrl_set_phase。

關節姿態目標（單位：度） Motor Control

索引 0–5 依序為 J1–J6；完整名稱可由 ctrl_joint_name(i) 查詢，各關節限位見上方模型表。兩個設定函數成功回傳 0，無效索引、非有限數值或尚未初始化時回傳 −1。

函數作用
ctrl_set_target_deg(i, deg)設定單一目標，限制在 joint range 內
ctrl_set_pose_deg(pose[6])設定六個目標並進入姿態模式
ctrl_get_target_deg(i)查詢使用者要求的目標角；不等同當前角度或內部斜坡目標
ctrl_get_min_deg(i) / ctrl_get_max_deg(i)查詢模型關節限位
ctrl_hold_current()捕捉目前六個角度並進入姿態保持
ctrl_home_targets()以 XML home keyframe 設定六個目標，平順回 home，不瞬移 qpos
ctrl_zero_targets()字面上的六個全零目標；與 home 不同，不代表碰撞安全姿態
double pose[6] = {10, 65, -100, 0, 35, 0};
ctrl_set_pose_deg(pose);
/* 每個物理步仍呼叫 ctrl_apply(); sim_step(); */

姿態模式使用質量矩陣縮放的 PD（位置與速度回授），加上偏置／被動力補償：依模型慣量、重力與阻尼把目標加速度轉成馬達力矩，並在 Euler 步進啟用隱式阻尼時作等效慣量修正，不補償接觸力。內部目標斜坡上限為 30°/s，並不是實際關節速度的硬限制；暫停時可先編輯目標，恢復後才移動。

正式模型、姿態控制與幾何三項 CTest 全通過（0.48 秒）：包含五個無引擎接觸靜態樣本、追蹤／保持／姿態捕捉、全零／home／reset，以及限位、限幅和真實阻擋時的有限數值。驗證僅限所測樣本，原型圖不替代控制測試；互動 GUI 的鍵盤操作尚未實測。

教學力矩額定：所有模式均使用 ±1 控制範圍，J1–J6 gear 為 12／20／12／3／3／2。模型密度與慣量尚未以硬體校準，額定餘裕也不保證任意姿態或碰撞路徑可達。
void ctrl_apply() Motor Control

姿態模式計算斜坡目標，以質量矩陣縮放 PD，再加入偏置／被動力補償；最後依 gear 轉成有限幅的馬達控制值。phase 模式寫入目前 preset，兩者都寫入 sim_data()→ctrl[]。

在主迴圈中每次 sim_step() 之前呼叫：

while (sim_data()->time - start < SIM_PER_FRAME) {
    ctrl_apply();   /* ← 寫入 ctrl[] */
    sim_step();     /* mj_step 讀取 ctrl[] 並積分 */
}
void ctrl_set_motors(const double ctrl[6]) Motor Control

直接將六個值寫入 d→ctrl[0..5]，順序為 J1、J2、J3、J4、J5、J6，不透過 phase 邏輯。

參數說明
ctrl[6]六個 motor 的控制輸入；所有模式都受模型的 ±1 控制範圍限制
注意：若主迴圈持續呼叫 ctrl_apply()，每個物理步都會用當前模式的輸出覆蓋此處的設定。 手動控制時，在主迴圈中以 ctrl_set_motors() 取代 ctrl_apply()。

int viewer_init(int width, int height, const char *title)

建立 GLFW 視窗並完成視覺化初始化：

  1. glfwInit() + glfwCreateWindow()
  2. 啟用 vsync（glfwSwapInterval(1) → ~60 fps）
  3. 註冊 keyboard / mouse button / mouse move / scroll callback
  4. mjv_makeScene + mjr_makeContext（需要 OpenGL context，glfwMakeContextCurrent 後才可呼叫）
  5. 設定核准預覽相機：lookat (0.19, 0, 0.32)、distance 1.12 m、azimuth 105°、elevation −14°
前置條件：必須在 sim_load() 之後呼叫（需要 sim_model()）。
Returns：1 成功，0 失敗。
void viewer_free()

釋放順序：mjr_freeContext → mjv_freeScene → glfwDestroyWindow → glfwTerminate。

int viewer_should_close()   int viewer_is_paused()

viewer_should_close：Esc 或點擊 ✕ 後為 1，主迴圈的終止條件。

viewer_is_paused：為 1 時主迴圈跳過 sim step，畫面凍結但仍可旋轉視角。

void viewer_render()

一幀的完整渲染流程：

  1. glfwGetFramebufferSize：取得實際 pixel 大小（HiDPI 適配）
  2. mjv_updateScene：從 model / data 計算場景幾何
  3. mjr_render：OpenGL 繪製
  4. mjr_overlay：左上角疊加 HUD（模式、暫停、各關節目標／實際角度、選擇、ctrl、快捷鍵）
  5. glfwSwapBuffers：顯示（vsync 在此阻塞，約 16 ms）
  6. glfwPollEvents：觸發所有 input callback

main主迴圈模式

main.c 不持有任何狀態，只負責串接與時序控制。

sim_load(MODEL_PATH);
ctrl_init();
viewer_init(1200, 900, "MuJoCo - 6-DoF Arm");

while (!viewer_should_close()) {
    if (!viewer_is_paused()) {
        mjtNum start = sim_data()->time;
        while (sim_data()->time - start < SIM_PER_FRAME) {
            ctrl_apply();   /* [Motor Control] 寫入 ctrl[] */
            sim_step();     /* 推進 2 ms */
        }                   /* ≈ 8 次 / 幀，維持實時速度 */
    }
    viewer_render();        /* 渲染 + vsync */
}

viewer_free();
sim_unload();

擴充：手動控制 motor

以 ctrl_set_motors() 取代 ctrl_apply()，直接傳入控制值，仍受模型 ±1 範圍限制：

/* 正弦波控制範例 */
double t = sim_data()->time;
double action[6] = {sin(t * 2.0), cos(t * 1.5) * 0.5, 0, 0, 0, 0};
ctrl_set_motors(action);
sim_step();

擴充：讀取完整狀態

/* 角度與角速度 */
double yaw   = sim_joint_angle_deg("J1_base_yaw");
double yaw_v = sim_joint_vel_deg("J1_base_yaw");

/* body 世界座標 */
double pos[3];
sim_body_pos("tool_roll", pos);   /* pos = {x, y, z} */

/* actuator 實際輸出力 */
double f_yaw   = sim_actuator_force(0);  /* J1 actuator */
double f_pitch = sim_actuator_force(1);  /* J2 actuator */
